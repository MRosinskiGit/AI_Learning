# Statistics and Machine Learning Learning Repository

Repository containing projects for learning Statistics and Machine Learning concepts.

## Development Requirements
- **Python 3.13** 

## Current Projects

1. **Linear Regression Comparison**  
   - Implemented two approaches:
     - **Custom recurrence algorithm** with step reduction to find local minima.
     - **Gradient descent method**.
   - Compared results with `scikit-learn`'s linear regression model.
   - Added visualizations for performance and convergence analysis.

2. **K-Nearest Neighbors (KNN) Project**  
   - Implementation and evaluation of the KNN algorithm.
   - Includes dataset preprocessing, model training, and accuracy testing.
